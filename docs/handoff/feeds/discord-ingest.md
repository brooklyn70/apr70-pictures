## Ingest architecture: n8n Discord Trigger → Paperclip issue create

n8n has a built-in **Discord Trigger** node that opens a Gateway WebSocket using the bot token and emits an n8n event per message. The workflow shape:

```
[Discord Trigger]
   ↓ (filter: not_a_bot && (mentioned || keyword_match))
[Function: enrich]  (extract serverId, channelName, authorTag, content, attachments)
   ↓
[HTTP Request: Paperclip create issue]
   ↓
   (POST /api/companies/<id>/issues with body:
    { title: "[Discord] <channelName>: <first 60 chars>",
      description: "Server: <server>\nAuthor: @<tag>\n\n<content>\n\nAttachments: <urls>",
      labels: ["feed:discord", "server:<serverShort>"]
    })
```

Auth header uses an **agent API key** for the Archivist (minted via T00 step 5). Don't store a board credential in n8n.

Output dir mirror: also write to `~/ObsidianVault/operations/feeds/discord/<server>/<channel>/<isoTimestamp>-<authorTag>.md` so the Archivist can re-read and Quartz can publish (Quartz excludes `_private/` only).
